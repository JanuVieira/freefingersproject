# Free Fingers

Experimento para desenhar no ar usando uma webcam e movimentos das mãos.

- **Dedo indicador** para desenhar.
- **Mão aberta** para apagar.
- **Cores** mudam automaticamente a cada 10 segundos.

Desenvolvido com JavaScript, p5.js e MediaPipe.

**[Experimentar](https://januvieira.github.io/freefingersproject/)**
